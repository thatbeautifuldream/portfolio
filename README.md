# Milind's portfolio

Next.js App Router portfolio with a static export, English and Hindi content, Markdown/MDX articles, public JSON and Markdown APIs, and native React view transitions and Next.js-generated social images.

Use Node 22.12+ and pnpm.

| Command               | Purpose                                                                                               |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| `pnpm install`        | Install dependencies                                                                                  |
| `pnpm dev`            | Generate content/resources and start Next.js on port 4321                                             |
| `pnpm check`          | Check TypeScript                                                                                      |
| `pnpm build`          | Generate content/resources, export Next.js to `out`, and mirror it to `dist`                          |
| `pnpm preview`        | Serve the production export on port 4321                                                              |
| `pnpm verify`         | Formatting, TypeScript, and production build                                                          |
| `pnpm test:agentic`   | Validate public APIs, Markdown exports, and hosting rules                                             |
| `pnpm test:migration` | Compare every migrated route with the captured Astro baseline, plus native OG image regression checks |
| `pnpm lighthouse`     | Audit mobile and desktop builds                                                                       |

Routes are statically generated by `src/app/[[...path]]`. Server-rendered page views live in `src/views`, reusable UI in `src/components`, and original authored content in `src/content`. `scripts/generate.ts` compiles content and produces the public resource endpoints from `src/resources`; generated output is ignored by Git. Edit centralized SEO in `src/lib/seo.ts`.

Vercel serves `out` using the redirects, Markdown negotiation, API fallback, security headers, and caching rules in `vercel.json`. The local preview mirrors those response headers. Portfolio links use the Next.js router and React ViewTransition, preserving the original cross-blur navigation and diagonal theme wipe. Downloads and external destinations retain browser navigation. Enhancement scopes clean up document listeners, timers, and observers when pages unmount; analytics remain deferred.

OG and story images are statically exported from App Router Route Handlers with `next/og` ImageResponse. They retain the existing URLs, dimensions, palette, fonts, and layout. Hindi cards use current Satori/HarfBuzz shaping before ImageResponse composition because Next.js bundles an older Satori version. PNG encoding and rasterization differ from the original CanvasKit output.

The migration baseline in `scripts/fixtures/astro-parity.json` captures page content/metadata and resource hashes before the framework change. The native OG fixture records the reviewed renderer output separately. Intentional future content, SEO, or image design edits require updating the matching expectations.
