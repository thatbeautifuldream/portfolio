# Milind's portfolio

Next.js App Router portfolio with a static export, English and Hindi content, Markdown/MDX articles, public JSON and Markdown APIs, and CanvasKit-generated social images.

Use Node 22.12+ and pnpm.

| Command               | Purpose                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| `pnpm install`        | Install dependencies                                                                              |
| `pnpm dev`            | Generate content/resources and start Next.js on port 4321                                         |
| `pnpm check`          | Check TypeScript                                                                                  |
| `pnpm build`          | Generate content/resources, export Next.js to `out`, and mirror it to `dist`                      |
| `pnpm preview`        | Serve the production export on port 4321                                                          |
| `pnpm verify`         | Formatting, TypeScript, and production build                                                      |
| `pnpm test:agentic`   | Validate public APIs, Markdown exports, and hosting rules                                         |
| `pnpm test:migration` | Compare every migrated route with the captured Astro baseline, including byte-identical OG images |
| `pnpm lighthouse`     | Audit mobile and desktop builds                                                                   |

Routes are statically generated by `src/app/[[...path]]`. Server-rendered page views live in `src/views`, reusable UI in `src/components`, and original authored content in `src/content`. `scripts/generate.ts` compiles content and produces the public resource endpoints from `src/resources`; generated output is ignored by Git. Edit centralized SEO in `src/lib/seo.ts`.

Vercel serves `out` using the redirects, Markdown negotiation, API fallback, security headers, and caching rules in `vercel.json`. The local preview mirrors those response headers. Client enhancements preserve ordinary link navigation, native document transitions, theme persistence, and deferred analytics.

The migration baseline in `scripts/fixtures/astro-parity.json` captures page content/metadata and resource hashes before the framework change. Intentional future content or SEO edits require updating those expectations.
